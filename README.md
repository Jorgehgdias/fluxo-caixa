# Fluxo de Caixa Rápido

Ferramenta web para montar, durante a visita ao cliente, o fluxo de caixa dos últimos 6 meses (DRE simplificada) e uma análise da saúde financeira da empresa para apoio à análise de crédito.

- Faturamento mensal informado manualmente (6 meses)
- Despesas fixas (R$) ou percentuais sobre o faturamento, com grupos
- Fluxo de caixa calculado automaticamente: Receita, despesas, total e Saldo
- Indicadores: margem líquida, margem de contribuição, ponto de equilíbrio, tendência, estabilidade, peso da folha, comprometimento financeiro, meses negativos e capacidade de pagamento
- Exportação em PDF com Razão Social e CNPJ no cabeçalho (com versão para impressão como alternativa)

Funciona 100% no navegador, sem banco de dados: os dados ficam apenas no aparelho de quem preenche.

## Publicação

Hospedado via GitHub Pages: *Settings → Pages → Deploy from a branch → main / (root)*.
